# داشبورد فارسی تحلیل داده

[English version](readme.md)

یک داشبورد راست‌به‌چپ با Streamlit برای بارگذاری فایل‌های CSV و Excel، بررسی کیفیت داده، پاک‌سازی انتخابی، فیلترکردن و ساخت نمودارهای تعاملی.

## امکانات

- رابط کاربری فارسی و راست‌به‌چپ
- بارگذاری فایل‌های CSV، XLSX و XLS
- نمایش پروفایل ستون‌ها، مقادیر خالی، موارد تکراری و آمار توصیفی
- فیلترهای عددی، تاریخی و دسته‌ای
- پاک‌سازی اختیاری داده‌ها و دریافت خروجی CSV از داده‌ی پردازش‌شده
- نمودارهای تعاملی و نقشه‌ی همبستگی

## ساختار پروژه

| مسیر | کاربرد |
| --- | --- |
| `app.py` | نقطه‌ی ورود برنامه و چیدمان صفحه‌ها |
| `src/dashboard/data_loader.py` | اعتبارسنجی و خواندن فایل‌ها |
| `src/dashboard/data_profile.py` | پروفایل‌سازی و پاک‌سازی داده |
| `src/dashboard/filters.py` | فیلترهای تعاملی |
| `src/dashboard/charts.py` | ساخت نمودارها |
| `src/dashboard/exporters.py` | آماده‌سازی خروجی CSV |
| `src/dashboard/ui_components.py` | اجزای رابط کاربری |
| `assets/styles.css` | استایل و چیدمان راست‌به‌چپ |
| `data/sample_sales.csv` | داده‌ی نمونه‌ی عمومی |

## پیش‌نیازها

- Python نسخه‌ی 3.14 یا بالاتر

## اجرا

در ترمینال پوشه‌ی پروژه، محیط مجازی بسازید و وابستگی‌ها را نصب کنید:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

در macOS یا Linux، محیط مجازی را با این فرمان فعال کنید:

```bash
source .venv/bin/activate
```

برای شروع، `data/sample_sales.csv` یا فایل خودتان را از نوار کناری بارگذاری کنید. فیلترها و تنظیمات پاک‌سازی را انتخاب کنید و سپس از بخش خروجی، CSV پردازش‌شده را دریافت کنید.

## داده و حریم خصوصی

- داشبورد فایل‌هایی را پردازش می‌کند که کاربر انتخاب می‌کند. در نمایش‌های عمومی از داده‌های واقعی یا محرمانه استفاده نکنید.
- نام فایل بارگذاری‌شده در لاگ برنامه ثبت نمی‌شود.
- فایل `data/sample_sales.csv` نمونه‌ی عمومی همراه پروژه است.
